# SocialMediApp

A full-stack social media web application built with the MERN stack (MongoDB, Express.js, React, Node.js) that allows users to register, login, post content, follow other users, and chat in real-time.


## 🚀 Features

- User authentication using JWT
- Create and delete posts
- Like and comment on posts
- Follow/unfollow other users
- Real-time private chat using Socket.io
- Responsive UI design using Bootstrap
- MongoDB Atlas for cloud data storage

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Axios
- Bootstrap

**Backend:**
- Node.js
- Express.js
- MongoDB (Atlas)
- JWT Authentication
- Socket.io for real-time communication
